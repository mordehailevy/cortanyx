# Audit audit-design-a11y — tour 1
Note : 8/10 (Design 9/10, Accessibilité 8/10, globale = la plus basse) — NON VALIDÉ (aucun BLOQUANT ; 1 MAJEUR restant)

Méthode : remesure dans un nouvel onglet (fermé, preset desktop remis). 0 message envoyé au chat, aucune conversation créée, rien supprimé. Menus et dialogues ouverts puis fermés par Échap, sans enregistrer. 375 réel (le volet autorise maintenant 375 exact), 768, 1024 et 1440 : aucun défilement horizontal. Contrastes mesurés en clair et en sombre. Thème laissé en clair, barre latérale dépliée.

## Ce qui est excellent
- **Tiroir mobile (375 px)** : à l'ouverture, le focus va sur « Cortanyx home » dans le tiroir. 30 Tab de suite : le focus reste dans le tiroir. `<main>` est `inert` (1 élément inert, 0 après fermeture). Échap ferme le tiroir et le focus revient sur « Open menu ». Aucune cible < 44 px dans le tiroir.
- **Cibles tactiles à 375 px** : tous les boutons mesurés sont ≥ 44 px (seul reste un lien dans le texte d'un message, 195×43, exempté). Bouton envoyer 44×44. Items de menu 35 px sur bureau avec `max-md:min-h-11`.
- **Conversation active** : en clair `#0f172a` sur `#f1f5fd` = 16,34:1 ; en sombre `#e2e8f0` sur `#1e293b` = 11,87:1. Barre `before:` de 3 px (`#3b82f6` en sombre) : l'état actif ne dépend plus de la couleur du texte (ancien 4,31:1).
- **Tokens ajoutés** : `--color-on-destructive` : bouton Delete 4,83:1 en clair, 5,84:1 en sombre (`#450a0a` sur `#f87171`, ancien 2,77:1). `--color-input` : contour du composeur mesuré `rgb(131,146,168)` = 3,16:1 sur blanc, 3,02:1 sur la surface ; en sombre `rgb(100,116,139)` = 3,96:1 sur le fond, 3,75:1 sur la surface (ancien 1,19 et 1,29). Le champ de renommage utilise le même token.
- **Menus** : `aria-label` présent (« Options for Salutation… »), Home/End vérifiés (End → Delete, Home → Pin), focus visible des `menuitem` = anneau inset 2 px bleu (`box-shadow ... rgb(37,99,235) 0 0 0 2px inset`). Le menu d'en-tête de conversation : Rename → dialogue → Échap → focus bien rendu au bouton « Conversation options ».
- **Autres corrections** : titre dynamique (« Conseils pour débuter en React · Cortanyx »), `lang="he"` posé sur les titres hébreux de la barre latérale (2 éléments), `useReducedMotion` + `behavior: reduce ? 'auto' : 'smooth'` dans ChatPage (lignes 14, 167-171). Textes secondaires toujours ≥ 6,96:1 (clair et sombre), « Copy »/« Regenerate » 7,58:1 en clair et 7,34:1 en sombre ; « Copy code » (`oklch` ≈ slate-300 sur `#161b22`) lisible (le 1,99 renvoyé par mon script vient du format oklch non analysé, pas du rendu). Piège de focus des dialogues correct (Tab ×4 reste dans la fenêtre).
